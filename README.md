# 🍔 Zynth Grill - Enterprise Food Delivery & Management System

A professional, full-featured enterprise management and single-page food delivery application (SPA) built for Zynth Grill in Nawabshah. Designed for smooth local operations, live order tracking, and multi-role staff management without heavy backend complexities.

---

## 🌟 Key Features

* **Customer Ordering Portal:** Interactive menu with categories, live search filters, real-time cart subtotal calculation, delivery fee rules, and specific Nawabshah delivery locations (QUEST University, SBBU, PUMHS, etc.).
* **Flexible Payments:** Supports Cash on Delivery (COD) as well as online transfers (EasyPaisa / JazzCash verification via Transaction ID).
* **Live Order Tracking:** Customers can instantly track their live order status using unique Order IDs (e.g., `ZG-1234`).
* **Role-Based Staff Portals:** Secure hidden access points for management and staff:
  * 🍳 **Kitchen Display System (KDS):** Live order queue for chefs to manage preparation and dispatch steps.
  * motorcycle **Riders Dispatch Panel:** Delivery tracking and status updates for local couriers.
  * 📊 **Admin & Manager Dashboard:** Real-time revenue analytics, total orders count, customer complaints log, and system reset controls.
* **Dynamic Menu Management (CRUD):** Admin can add new dishes, update prices, change image URLs, or toggle stock status (`In Stock` / `Out of Stock`) instantly.

---

## 🚀 Tech Stack

* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript.
* **Icons & Fonts:** FontAwesome 6, Google Fonts.
* **Data Persistence:** Browser `localStorage` for zero-configuration, seamless local and hosted execution.
